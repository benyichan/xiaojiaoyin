# 小脚印 · 宝宝成长记录 App（M1-M5）

完全离线的本地宝宝成长记录 Android App。M1：骨架 + 宝宝档案 + 首页动态流 + 备份恢复 + 待办提醒；M2：相册 + 成长时间轴；M3：生长曲线 + 统计看板；M4：医疗/喂养/哭闹专区、学籍、好物、那年今日；M5：共享同步 + 订阅变现 + 上架合规包。

## 技术栈

- Kotlin 2.2.21 + Jetpack Compose + Material 3
- Navigation 3（1.1.0）
- Room 2.8.2 + DataStore 1.1.7
- lunar-java（`cn.6tail:lunar:1.7.7`）农历/八字
- AGP 8.13.2 / Gradle 8.14.3 / compileSdk 36 / minSdk 26

> 版本说明：2026.08 的新版依赖（Compose BOM 2026.08、core-ktx 1.19 等）要求 AGP 9.1 + compileSdk 37，本机 SDK 最高 36，因此选用 2025.12 代稳定组合。

## 已实现

### M2：相册与成长时间轴

- 相册：从文件选择器添加照片（自动压缩到 1600px 存私有目录）、按月分组照片墙、备注角标、点开预览、编辑备注、删除（连带文件）、按备注搜索
- 成长时间轴：重要节点（标题/日期/时间/备注）、时间轴样式（金色节点 + 卡片）、⭐ 重要徽章、按月分组、按标题/备注搜索、详情查看、删除
- 首页动态流新增相册/节点卡片，首页"拍照"快捷可直接选图添加照片

### M3：生长曲线与统计看板

- WHO 儿童生长标准离线数据（0-60 月，男女，身高/身长 + 体重），assets CSV 内置
- 生长曲线页：身高/体重切换、WHO P3/P50/P97 参考线 + 宝宝数据点、历史记录列表（日期/数值/BMI/评估）
- 统计看板：生长曲线入口、喂养统计（最近 14 天每日次数柱状图）、哭闹分布（原因占比条形）
- 图表全部用 Compose Canvas 手绘，零图表库依赖

### M4：专区补全

- 医疗记录：疫苗/体检/就诊/用药分类筛选、添加表单（分类/标题/日期/详情）、详情查看、删除
- 喂养专区 / 哭闹专区：记录列表页 + 添加入口（复用记录表单）
- 学籍信息：多阶段管理（幼儿园到大学），阶段表单（类型/班级/学校/老师/起止/学号/备注），详情查看、删除
- 好物清单：添加（名称/1-5 星评分/备注）、星级展示、详情、删除
- 那年今日：按"月日相同、年份不同"自动聚合往年记录，空状态友好提示
- "我的"页接入全部专区入口；首页动态流支持医疗卡片
- 数据库升级 v2（新增学籍/好物表），开发期用 fallbackToDestructiveMigration（正式版需迁移策略）

### M5：共享同步 / 变现 / 合规

- 变更集同步核心：五张表（宝宝/记录/待办/学籍/好物）统一为 SyncChange（table+id+updatedAt+json），合并规则"按更新时间取新，同时刻本地优先"，纯函数可单测
- Wi-Fi 局域网同步：接收端 ServerSocket + 发送端 Socket，裸 Socket 传变更集 JSON；已在本机回环验证全链路（收到 630 字节 → 合并 4 条 → 双方一致）
- 文件同步兜底：导出变更集文件 / 导入合并（无网络可用）
- 数据库 v3：record 增加 updatedAt，保留数据迁移（MIGRATION_2_3）
- 变现（2026-08-15 定稿）：**付款 + 邮箱激活码**，不走商店 IAP
  - 定价：月度 ¥6.8 / 月，年度限时 ¥59 / 年（原价 ¥76.9，77 折，18 小时倒计时），永久买断 ¥159（= 2.5 年月费 ¥204 × 80%，取末尾 9）
  - 激活码：HMAC-SHA256 签名 + base32，绑定设备 ID + 到期时间；App 显示设备 ID → 扫码付款 → 邮件申请（benyi@aliyun.com）→ 回复激活码 → 输入激活
  - 卖家端生成工具：`scripts/generate_license.py`；流程说明见 docs/monetization.md
  - Pro 状态与到期时间本地存储（DataStore）
- 合规包：docs/compliance/ 隐私政策、Google Play 家庭政策清单、国内发布清单
