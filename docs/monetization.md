# 变现方案：付款 + 邮箱激活码

## 定价（2026-08-15 定稿）

| 套餐 | 价格 | 说明 |
|---|---|---|
| 月度 | ¥6.8 / 月 | 到期前可续费（生成新的月费码） |
| 永久买断 | ¥159 | ≈ 2.5 年月费（¥204）× 80% = ¥163.2，取末尾 9 → ¥159 |

## 购买流程

1. 用户在 App「我的 → 订阅升级」页选择套餐（月度/永久）、扫码付款
2. 用户点「复制申请内容」→ 粘贴到邮件（含设备 ID、套餐、回执邮箱），发到 **benyi@aliyun.com**
3. 开发者收到邮件，用 `scripts/generate_license.py` 生成激活码，**回复邮件**给用户
4. 用户在 App 输入激活码，本地验证签名 → 激活 Pro（永久码永久有效；月费码含到期时间）

## 生成工具

```bash
python scripts/generate_license.py <设备ID8位hex> M    # 月费（30 天）
python scripts/generate_license.py <设备ID8位hex> L    # 永久
python scripts/generate_license.py <设备ID8位hex> M <unix秒>  # 指定到期
```

## 激活码格式

- payload = `XY` + 设备ID(4B) + 套餐(1B: M/L) + 到期时间(4B，0=永久)
- 签名 = HMAC-SHA256(payload, 密钥) 前 4 字节
- 激活码 = base32(payload + 签名)，24 字符，展示为 `XXXX-XXXX-XXXX-XXXX`
- App 验证：签名校验 → 设备 ID 匹配 → 月费码到期时间未过

## 安全说明

- 激活码**绑定设备**：复制给别人无法在其他设备激活
- 密钥内置客户端，可被逆向提取后自制激活码——纯离线方案下的已知限制，属"防误操作级"保护
- 若后续用户量大、需要强防伪：改为服务器签发/验证，客户端仅展示码
