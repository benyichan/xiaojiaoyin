# 国内应用商店发布清单

## 法律与资质

- [ ] 软件著作权登记（《小脚印》V1.0）
- [ ] ICP 备案（若接入任何域名；当前完全离线，通常无需）
- [ ] 工信部 App 备案（2023 年后上架硬性要求，需企业/个人主体）
- [ ] 隐私政策（docs/compliance/privacy-policy.md）放入应用内"关于"页并链接商店

## 各商店材料

- [ ] 华为应用市场：权限声明、隐私政策、软著、应用截图
- [ ] 小米应用商店：同上 + 隐私检测（儿童应用需家长确认声明）
- [ ] OPPO/vivo/应用宝：同上，注意各商店对"儿童类"应用的额外审核
- [ ] 加固与签名：正式签名 keystore、商店加固（可选）

## 权限合规（国内）

- [ ] 权限最小化声明：仅在功能需要时申请
- [ ] 通知/精确闹钟权限在首次使用时引导并说明用途
- [ ] 避免"过度索取"：不申请电话、通讯录、定位等无关权限

## 发布前自检

- [ ] 数据库迁移策略：当前 v3 用保留数据迁移，上架前需完整回归升级路径
- [ ] 正式签名 release 构建 + 真机全机型抽测（重点：国产 ROM 提醒可达性）
- [ ] IAP 接入：国内各商店 SDK（华为 IAP、小米支付等）需按商店集成，Google Play 用 Billing 库
