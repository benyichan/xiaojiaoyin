# 小脚印隐私政策

生效日期：2026-08-15（草案，上架前需由法律顾问复核）

## 一、我们如何处理您的数据

**小脚印是一款完全离线的本地记录应用。** 您的所有数据——宝宝档案、成长记录、照片、医疗记录、待办事项等——均仅存储于您自己的设备上，不会上传到任何服务器。

- 我们不收集、不传输、不出售任何个人信息
- 应用内所有功能（含共享同步）仅在同一 Wi-Fi 局域网内进行设备间直连传输，不经过公网
- 备份文件由您主动导出，保存在您自己选择的位置

## 二、儿童个人信息保护

本应用记录的是儿童（未成年人）的成长信息。依据《中华人民共和国个人信息保护法》《儿童个人信息网络保护规定》及 Google Play 家庭政策：

- 儿童信息的处理者为家长（监护人）本人，数据始终在家长设备上
- 应用不向儿童展示广告，不采集儿童行为数据
- 家长可随时导出、删除全部数据
- 应用没有账号体系，无法在服务端关联或识别任何儿童

## 三、权限使用说明

| 权限 | 用途 |
|---|---|
| 通知 | 待办事项到点提醒 |
| 精确闹钟 | 提醒准点触发 |
| 相机/相册 | 添加宝宝照片（仅用户主动选择时访问） |
| 蓝牙 | 无 Wi-Fi 时的设备间同步（待完善） |
| 忽略电池优化 | 保证后台提醒可靠触发（用户主动开启） |

## 四、数据导出与删除

- 备份与恢复：设置 → 备份与恢复，可导出完整备份文件或从备份恢复
- 删除：宝宝档案及各专区均提供删除入口；卸载应用即清除全部本地数据
